DCDistrict Nerve Center

Bajaur · Khyber Pakhtunkhwa — installation and daily use

This system records every emergency reported anywhere in Bajaur, sends it to the department responsible, and keeps a permanent account of what was done about it. It is the district's record — not a summary of one kept somewhere else.

There are two things to set up, and they are different jobs. One office machine runs the system. Everybody else — duty officers, department staff, the control room — opens it from that machine over the district's own network, on a phone or a laptop. Nothing is installed on their devices.

Part 1 — The office machine

Do this once, on the computer that will hold the district's record.

What it needsWhy
Windows 10 or 11, 64-bit The installer is a Windows program.
An administrator account So the system can start itself after a power cut, without anybody signing in.
About 1 GB of free disk space 500 MB for the program, and room for the record to grow.
A machine that stays on Reports arriving from the field are accepted whenever this machine is running. While it is off, handsets hold their reports and deliver them when it comes back — nothing is lost, but nobody in the control room sees them until then.
Nothing else has to be installed first. The database and everything else the system needs are inside the installer. It does not download anything and it does not need the internet to install.
1

Run DistrictNerveCenter-Setup-1.0.0.exe

Windows will ask "Do you want to allow this app to make changes?" — choose Yes. It may first show a blue "Windows protected your PC" box, because this installer has not been submitted to Microsoft for signing. Click More info, then Run anyway.

2

Fill in the administrator account

Setup asks for the name, mobile number and a password of the person who will set the system up for the district. This is the only account that exists at first, and it is the one that adds departments, sets routing, and gives everybody else their login.

  • Use the mobile number the district already knows for that person. It is how they sign in and how the system reaches them.
  • The password must be at least 12 characters. Write it down somewhere safe before you type it.
3

Wait for it to finish

After the files are copied, Setup spends about a minute preparing the district's record — creating the database, and loading the 79 offices and 81 posts from the district's own contact list. It will say so on screen.

4

Open it

There is now a District Nerve Center icon on the desktop, and an entry in the Start Menu. Click it and the system opens in the browser. Sign in with the number and password from step 2.

To keep it on the taskbar: find it in the Start Menu, right-click, Pin to taskbar.

What happens from then on

The system starts by itself whenever the machine starts, including after a power cut and before anybody signs in. The desktop icon does not start it — it just opens it. If for any reason it is not running when you click the icon, the icon starts it and then opens it, so clicking it is always the right thing to do.

Part 2 — Phones and other computers

Everybody else reaches the system over the district's network. There is nothing to install and no app store involved.

1

Find the address

On the office machine, open the Start Menu → District Nerve Center → Check the District Nerve Center. It prints a line like:

On the network at http://192.168.1.40:3000
On the district's domain https://dnc.bajaur.gkp.pk

Give people the https:// address, not the number. Both reach the same machine in this office, and only the https:// one lets a phone keep the app working with no signal or use the phone's location. Opened by number it looks like it worked, and then does not work at the scene — which is the one thing this system exists to prevent. The number is for checking the machine from the office, nothing else.

If the second line is missing, the district's domain has not been pointed at this machine yet — see Putting it on a phone, and R-21 in the district's list.

2

Give each officer a login

Sign in as the administrator, go to Administration → the department's roster, and grant an account to the people who need one. Everybody in the district's contact list is already there and can already be reached — being contactable and being able to sign in are separate things, on purpose.

3

Add it to a phone's home screen

See the separate sheet, Putting it on a phone. It takes about fifteen seconds per handset and it is worth doing on every one: added to the home screen, it opens like an app, fills the screen, and — importantly — still opens and still accepts an emergency report when the phone has no signal at all.

The first thing to do inside the system

Until you set a routing signal, every emergency arrives unassigned. This is deliberate and it is loud: the system never guesses which department should answer. It shows "with nobody" on the dashboard until the district says who answers for what.

Sign in as the administrator, open Administration, choose a department, and give it a signal — a category such as fire, or a keyword. From that moment, emergencies matching it go to that department's duty officer with a clock running against an acknowledgement deadline. More than one department matching the same emergency is a correct answer, not a conflict.

Two more worth doing in the first week:

  • Check the acknowledgement deadlines. The ones in the system now are placeholders until the district sets its own.
  • Fill in the missing numbers. 38 posts in the contact list have nobody in them, and the Rescue 1122 number is a visible stand-in. Anything that is a placeholder says so on screen.

Backups

Every night at 02:00 the system takes a copy of the district's record, checks the copy is complete, and writes down whether it worked. You can see this under Administration → Backups, and take one on demand from the same screen.

Those copies never leave the building yet. Fire, flood or theft at the office would take the record with it. Sending an encrypted copy off-site is built and tested but switched off, because it needs a cloud storage account the district has not yet provided. The Backups screen says this plainly rather than showing a green tick.

If something is wrong

What you seeWhat to do
Clicking the icon does nothing, or the browser says it cannot connect Open Start Menu → Check the District Nerve Center. It says whether the database and the server are running. If either says stopped, click the desktop icon again — it starts them.
The board says NOT LIVE — do not act on this without checking This is the system being honest, not broken: that screen has not reached the server for 30 seconds, so what is on it may be out of date. Do not decide anything from it until it clears. Check the network between this machine and the office one.
Phones on the district network cannot reach it They are probably on a different network, or Windows Firewall blocked the rule during installation. Confirm the address from Check the District Nerve Center, and confirm the phone is on the same network.
An emergency shows as with nobody No department has a routing signal that matches it. That is the system telling the truth. Add the signal in Administration.

Removing it

Settings → Apps → District Nerve Center → Uninstall, in the ordinary way.

The record is not deleted when you uninstall. It stays in C:\ProgramData\District Nerve Center, which holds every emergency ever recorded on this machine. Installing again picks it up where it left off. Deleting that folder destroys the record permanently, and no backup taken by this system lives anywhere else yet.
